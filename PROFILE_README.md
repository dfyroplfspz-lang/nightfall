## 🎮 NIGHTFALL

Top-down зомби-выживание. Ночь, фонарь — единственный свет: зомби видно только там, куда он светит.

[![Скачать](https://img.shields.io/badge/СКАЧАТЬ%20ИГРУ-бесплатно-d6403a?style=for-the-badge)](https://dfyroplfspz-lang.github.io/nightfall/)
[![Сайт](https://img.shields.io/badge/сайт-github.io-111111?style=for-the-badge)](https://dfyroplfspz-lang.github.io/nightfall/)

| | |
|---|---|
| **5 режимов** | Survival · Endless Rush · Boss Rush · Nightmare · Time Attack |
| **5 карт** | парковка, сталелитейный цех, метро, больничное крыло, парк |
| **4 ствола** | пистолет, MP5, дробовик, АК — у каждого своя модель |
| **24 скина** | 12 на выжившего, 12 финишей на оружие, 4 редкости |
| **кейсы** | три типа, рулетка с редкостями, дубликаты идут в скрап |

Есть и 3D-версия: шутер от первого лица на ursina/panda3d, ночной квартал,
собственный GLSL-шейдер света, восемь типов зомби, гранаты, взрывные бочки и перки между волнами.
